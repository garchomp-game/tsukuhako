ツクハコ 0.4.8 — Linux Mint 22.3 x64向け候補

この候補は所有者による標準GUIでの初回導入・メニュー起動の確認待ちです。
Ubuntu・Debianや他のMint版を検証済みとして案内するものではありません。

1. tsukuhako-linux-amd64-0.4.8.deb をファイルマネージャーで開きます。
2. Linux Mint標準の「パッケージインストーラー」（Captain）で、名前と版を
   確認し、インストールします。管理者認証は本体・メニューをPCへ登録する
   ためのものです。OS側の不足ライブラリを取得する通信が必要な場合があります。
3. アプリケーションメニューで「ツクハコ」を検索して起動します。
4. 最初の画面の「はじめてのWeb画面で始める」を押します。
   説明を先に読む場合は「全体の流れを読む」、または上部の「ガイド」を開きます。
   アカウント登録は不要です。ガイドはオフラインでも読めます。
5. 「準備チェック」でDocker・VS Code等を確認します。本体の導入完了と
   開発環境の準備完了は別です。最初の候補は「はじめてのWeb画面」です。

通常の起動に端末・chmod・特別な起動フラグは不要です。
アプリを管理者として起動したり、OSやアプリの保護機能を無効にしないでください。
Node.js・npm・Python・ビルドツールは、本体の利用だけなら導入不要です。
準備やダウンロード・ビルドの所要時間はPC・回線により異なります。

起動後は、ダウンロードしたdebを別の場所へ移したり削除して構いません。
本体とガイドはPCへ導入済みです。再インストール用に保管しても構いません。

更新：ツクハコを閉じてから、今後提供する新しい版のdebを開いて更新します。
初回の更新試験は試験用の旧版で実施しています。過去のtar版は自動削除しません。
tar版から移る場合は旧版を閉じ、導入後はメニューから起動してください。

削除：ツクハコを閉じ、Mintのパッケージ管理画面（Synaptic等）でパッケージ名
「tsukuhako」を検索して削除します。本体とメニューが削除対象です。
生成したプロジェクト、Dockerのデータ、読書設定は残します。
読書設定等は通常 ~/.config/tsukuhako にあります（XDG_CONFIG_HOMEを指定した
環境ではその配下）。再導入すると設定を再利用します。

認証をキャンセルした場合や依存ライブラリの取得に失敗した場合は、画面の結果を
確認してください。成功とみなさず、通信状態と空き容量を確認してdebを開き直します。
原因が分からない場合は、表示された文言と操作した段階を記録してください。
起動できない場合も保護機能の無効化を試さず、エラーを記録してください。

外部の購入者向け受取先は未設置です。private GitHubは一般購入者の受取先では
ありません。公開販売、購入権限の検証、実メール配信は今回の実装範囲外です。
