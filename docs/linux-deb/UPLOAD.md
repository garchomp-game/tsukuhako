# 単体debの受取先を用意するとき

公開・販売開始は未実施。まず所有者がINSTALL.txtの導入経路を確認し、REPORTの未確認項目を埋める。

1. `dist/delivery-linux-deb-1.0.0/` のdeb、SHA256SUMS、INSTALL.txt、manifest.jsonを確認する。debのSHA-256はmanifestと照合する。
2. 既存の購入者向け受取先を決め、そのアクセス制御と利用期限を確認する。private GitHub・期限付きActions artifactのURLを一般購入者用にしない。
3. **単体debを直接受け取れるファイル**としてアップロードする。Linuxの主ボタンは「Linux Mint向け・ツクハコをダウンロード」。外側ZIPを必須にしない。案内とハッシュも並べる。
4. Brain本文、メール草稿、受取画面のLinuxリンクを同じdebへ合わせる。Windows候補は既存0.4.4のままで、新版の実機合格と混ぜない。
5. 購入者相当の権限でPCから取得し、ダウンロード後のSHA-256を確認する。スマートフォンの案内からPCで同じファイルを受け取れることも試す。
6. サーバーで購入権限を検証する仕組みがなければ、URLを知る人がアクセスできる状態と明記する。未実装の認証・R2配布・実メールを完成扱いしない。

L13は受取先が未設置のためNOT_RUN。アップロードや外部公開は別途ユーザーの指示を受けて行う。
