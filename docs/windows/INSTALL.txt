ツクハコ {{VERSION}} — Windows 11 x64（Intel / AMD）

1. {{INSTALLER}} を普段のWindowsユーザーで開きます。
2. 導入後は、スタートメニューから「ツクハコ」を起動します。
3. 「はじめてのWeb画面で始める」を押し、画面の案内に沿って進めます。
   Windowsでは、開発に使うWSLを選び、「WSL用ファイルを準備」を行います。
   保存先は選んだWSLのホームフォルダー内にします。
4. 作成後の「サンプル画面を表示する手順へ」を開き、
   「このフォルダーをVS Codeで開く」から、その下の手順へ進みます。

本体・教材の利用には、会員登録やPC側のNode.js・npm・Pythonは不要です。
サンプルを動かす段階で、WSL 2、Docker Desktop、Windows版VS Codeと
MicrosoftのWSL・Dev Containers拡張が必要です。アプリ内のWindows準備手順で
不足するものを確認できます。開発環境の初回起動にはネット接続が必要です。
Dev Container用の設定ファイルはツクハコが作成します。

現在のインストーラーは未署名です。Windowsの確認画面や組織の制限で停止する
場合があります。提供元を確認し、保護機能を無効化せず、表示された内容を
記録してください。Windows ARM向けではありません。
