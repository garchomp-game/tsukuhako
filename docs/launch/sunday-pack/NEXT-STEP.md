## 1. 変更前を残す — VS Codeの編集画面

いま動かしているF2の `app/page.tsx` を開きます。`h1` の中の次の文字をメモへコピーし、ブラウザの見出しも確認します。

```tsx
小さく変えて、<br />動きを確かめよう。
```

## 2. 文字だけ変えて保存する — VS Code → ブラウザ

`h1` タグと `className` は残し、その内側だけを次に変えて保存します。

```tsx
わたしの練習室
```

サーバーのターミナルは動かしたまま、**このプロジェクトのホスト側URL**を開きます。見出しが「わたしの練習室」になれば確認できています。反映されなければ [困ったとき](TROUBLESHOOTING.md)の該当行へ進みます。

## 3. 元へ戻して保存する — VS Code → ブラウザ

同じ部分を1番のメモの文字へ戻して保存し、ブラウザの見出しも元へ戻ったことを確認します。ファイル全体やプロジェクトの削除は不要です。

変更前・変更後・復元後の三つを確認できたら、この練習は完了です。続きは**生成先**の `docs/EXERCISES.md`、終了と再開は [TROUBLESHOOTING](TROUBLESHOOTING.md)を使います。
