# 任意：文字を変えて、元に戻す

[はじめて使うに戻る](START_HERE.md) · ガイド2026-10-24-r5

「はじめてのWeb画面」のサンプルが表示できたら、初回の目標は達成です。この練習は続けたい場合だけ行います。まだ表示できていない場合は、[初回の手順を確認する](FIRST-RUN.md)へ戻ります。

## 変更する文字を確認する

**VS Codeの編集画面**で、今動かしているプロジェクトの `app/page.tsx` を開きます。`h1` の中に次の文字があり、ブラウザーにも同じ見出しが表示されていることを確認します。

```tsx
小さく変えて、<br />動きを確かめよう。
```

## 文字を変えて表示する

`h1` タグと `className` は残し、その内側の文字だけを次に変えて保存します。

```tsx
わたしの練習室
```

サーバーのターミナルは動かしたまま、**表示中のサンプル画面**を確認します。見出しが「わたしの練習室」に変われば成功です。反映されない場合は[保存したファイルと表示中の画面を確認](#変更が反映されないとき)します。

## 元に戻して表示する

同じ部分を、この章の最初にある元の文字へ戻して保存します。ブラウザーの見出しも **「小さく変えて、動きを確かめよう。」** に戻れば、この練習は完了です。ファイル全体やプロジェクトの削除は不要です。

続きの練習は作成したフォルダーの `docs/EXERCISES.md` で読めます。今日は終える場合は[作業を終える](TROUBLESHOOTING.md#作業を終える)、後日続ける場合は[同じプロジェクトを再開する](TROUBLESHOOTING.md#同じプロジェクトを再開する)を使います。

## 変更が反映されないとき

VS Codeで編集したファイルが**今回のフォルダーの `app/page.tsx`** で、保存済みか確認します。次にブラウザーのURLが今回の手順と一致し、サーバーが動いているか確認します。表示自体が出ない場合は[サーバーとURLを確かめる](TROUBLESHOOTING.md#画面が表示されない)へ進みます。
