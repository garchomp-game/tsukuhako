# はじめて使う：F2の最初の画面まで

Linux版ツクハコ **0.4.5** 用・ガイド **2026-10-24-r3**。新版の導入を確認するための候補です。

ツクハコは、Next.jsなどのDev Container環境を生成するツールです。本体にガイドと教材を同梱しています。最初は **F2（Next.js）を一つ生成し、初期処理の正常終了を確認して、ブラウザに最初の画面を表示する** ところまで進みます。ほかの構成を比較する必要はありません。変更・復元は、表示できた後の任意の練習です。

## いま、ツクハコが開いている方へ

**次の一操作：[F2の初回手順](FIRST-RUN.md)を開き、1番の「現在地を見る」から進んでください。**

本体が開くこと、ガイドを読めること、Dockerなどの開発準備ができていることは別です。ガイドを読んだだけでは、準備チェックの結果は変わりません。

このガイドは上部の **「ガイド」** からいつでも開けます。「作る」画面の **「はじめて使う」** も同じ入口です。ダウンロードしたインストーラーを移動・削除しても、インストール済みの本体から読み続けられます。ガイドの閲覧にネット接続やMarkdown用の追加ツールは不要です。

## Linux Mintで、受取からメニュー起動まで

1. 案内された受取先でLinux Mint x64用の **`tsukuhako-linux-amd64-0.4.5.deb`** を保存します。通常の受取は、この単体debです。外側のZIPや、内側のtar.gzを順に展開する必要はありません。
2. ファイルマネージャーでdebを開き、OS標準の **「パッケージインストーラー」** で名前と版を確認します。Linux Mint 22.3のこの案内ではCaptainを使います。別のインストーラーを追加する手順ではありません。
3. 内容を確認してインストールします。管理者認証は本体をシステムへ配置し、メニューへ登録するためです。OS側の依存パッケージを取得する場合は通信が必要です。キャンセルや失敗の表示が出た場合は、導入できた扱いにせず[困ったとき](TROUBLESHOOTING.md)へ進みます。
4. 導入の完了を確認し、アプリケーションメニューから **「ツクハコ」** を起動します。普段の起動は通常ユーザーで行います。端末、chmod、起動フラグを用意する操作は通常の入口に含めません。
5. 「作る」画面の **「はじめて使う」** を開き、[F2の初回手順](FIRST-RUN.md)へ進みます。

本体の導入と教材閲覧のためだけに、Node.js、npm、Python、ビルドツールを追加する必要はありません。F2を初めて動かす段階では、ネット接続、Docker、VS Code、MicrosoftのDev Containers拡張が必要です。所要時間はPCの状態と取得するファイルにより変わります。

## 対象と、まだ確認が必要な範囲

| PC・配布物 | この案内での扱い |
|---|---|
| Linux Mint 22.3 x64・0.4.5 deb | 最初の検証対象。新版のGUI導入、通常ユーザーのメニュー起動などは実機での確認が必要です |
| 旧Linux版0.4.4 | Mint 22.3の既存開発環境でF2の一経路を確認した記録があります。新版debの導入成功や未準備PCの成功を示す記録ではありません |
| Windows x64・既存0.4.4 | 2026-10-25-b1の同梱ZIPを維持しています。ZIP内の `00_START_HERE.html` → `app/START_HERE.txt` → `guide/index.html` を使います。**Windows 11通常ユーザー・実WSL/F2は未確認**です。新しいWindows版の提供を意味しません |
| 他のLinux / macOS / ARM | この版での確認済み環境に含めません |

Windowsの未署名exeをServer 2022 CIで補助確認した記録も、Windows 11の実機確認とは異なります。このガイドのWindows欄は、既存0.4.4で検証協力する場合の参考です。

## 旧版と、削除するときの扱い

以前のtar版を自分のフォルダへ展開している場合、そのコピーを自動で探して削除しません。旧版を閉じ、導入後はメニューの「ツクハコ」を使い、画面上部の版を確認してください。生成したプロジェクトを移動・作り直す必要はありません。

本体を削除する場合はOSのパッケージ管理画面でツクハコを選びます。生成プロジェクト、Dockerのデータ、読書設定は本体とは別の利用者データです。削除・再導入や版更新の結果は、これらが残ることも含めて確認します。困ったときにデータや旧tarをまとめて消す必要はありません。
