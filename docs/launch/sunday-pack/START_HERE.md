# はじめて使う

**[サンプル画面を表示する手順を開く](FIRST-RUN.md)**

「はじめてのWeb画面」を選び、新しい開発用フォルダーを作ります。続いてVS Codeで開発環境を開き、自分のPCのブラウザーにサンプル画面を表示します。**画面が表示できたら、初回の目標は達成です。** 文字の変更・復元は、その後の任意の練習です。

## 始める前に知っておくこと

- この手順は **Linux Mint 22.3 x64・ツクハコ1.0.1** 向けです。ほかのOSへ同じ手順をそのまま適用しません。
- ファイルを作るだけならネット接続は不要です。**開発環境を初めて動かすときは、ネット接続とダウンロードの待ち時間が必要**です。
- 動かすまでにDocker、VS Code、MicrosoftのDev Containers拡張を用意します。**ツクハコはこれらを自動導入しません。** 不足があれば、[準備の状態を確認する](FIRST-RUN.md#準備を確認する)から必要な項目だけ進めます。
- 開発環境の設定ファイルはツクハコが作成します。自分で `.devcontainer` や `.env` を先に作る必要はありません。

## 途中から続ける

| 今の状態 | 次の操作 |
|---|---|
| まだ開発用フォルダーを作っていない | [準備の状態を確認して、フォルダーを作る](FIRST-RUN.md#準備を確認する) |
| フォルダーを作成したところ | 「作る」の作成結果で **「サンプル画面を表示する手順へ」** を押す。今回の保存先・URLが入った手順が開きます |
| 準備や操作の途中で止まった | [今の症状から対処を選ぶ](TROUBLESHOOTING.md) |
| アプリを閉じた後で続けたい | [同じプロジェクトを再開する](TROUBLESHOOTING.md#同じプロジェクトを再開する) |
| サンプル画面が表示できた | [作業を終える](TROUBLESHOOTING.md#作業を終える)。続けたい場合は[任意の変更・復元](NEXT-STEP.md)へ |

このガイドは上部の **「ガイド」** から開けます。ガイドの閲覧と内部の案内リンクにはネット接続が不要です。ネットが必要な操作は、それぞれの手順に書いてあります。ガイドを読んだだけでは、開発準備チェックの結果は変わりません。
