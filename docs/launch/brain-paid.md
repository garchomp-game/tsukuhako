# ツクハコを受け取ったら

ツクハコをご購入いただき、ありがとうございます。ツクハコは、Next.jsなどのDev Container環境を生成するツールです。最初は、使うPCに合う本体＋ガイドの同梱ZIPを一つ受け取り、入口の案内を開くところから始めてください。

## 1. 使うPCで、この購入済み記事を開く

スマートフォンで購入した方は、使うPCで同じBrainアカウントにログインし、この購入済み記事を開いてください。

購入前の説明で提供範囲を確認し、PCに合う受取先を選びます。x64はIntel/AMDの64bit向けです。ARM・macOS向けの配布物はありません。

| OS | 受取先 | 本体＋ガイドの同梱ZIP |
|---|---|---|
| Linux x64 | [Linux用の受取先]({{links.linuxDownload}}) | `tsukuhako-0.4.4-linux-x64-pack-2026-10-25-b1.zip` |
| Windows x64 | [Windows用の受取先]({{links.windowsDownload}}) | `tsukuhako-0.4.4-windows-x64-pack-2026-10-25-b1.zip` |

ZIP全体を展開し、展開先の **`00_START_HERE.html`** をブラウザで開いてください。本体と導入・照合の案内は `app/`、使い始めるためのガイドは `guide/` に入っています。最初の案内から **`app/START_HERE.txt`** へ進み、その手順で本体を照合・導入・起動します。

`SHA256SUMS` はファイルの一致を照合するためのものです。ハッシュの一致だけで発行者の本人確認ができるわけではないので、この購入済み記事から案内する受取先を使ってください。

Linuxの本体は `app/` 内のtar.gz、Windowsの本体は同じく `app/` 内の未署名のexeです。実際の展開・導入・起動は `app/START_HERE.txt` の手順を使ってください。警告で止まる場合はOSの保護を無効化せず、内容を控えて[窓口]({{links.support}})へ確認してください。Windows 11と実WSLでの開発経路は未確認であり、CIの成功を実機確認の代わりにはしていません。

## 2. アプリ起動後、F2の初回手順へ進む

アプリが起動したら、**`guide/index.html` の「F2の初回手順」** を開きます。同梱ガイドはブラウザで読めるため、Markdownを読むための追加ツールやネット接続は不要です。外部の導入先を見る場合はネット接続が必要です。アプリ上部の「学ぶ」から準備の教材も読めます。教材の閲覧と、生成した環境を動かすことでは、必要な準備が異なります。

開発を始めるときは、DockerとVS Code、MicrosoftのDev Containers拡張などを用意します。WindowsではWSL 2の通常ユーザーと、同じWSLへのDocker Desktop連携、VS CodeのWSL拡張も使います。初回は必要なファイルの取得があるため、インターネットに接続して進めてください。

導入済みのものを、最初からやり直す必要はありません。「作る」の準備チェックとOS別の教材を見ながら、現在の状態を確認します。[準備の確認ガイド]({{links.setupGuide}})も利用できます。

## 3. F2を生成して、プロジェクト固有の案内を開く

初回はガイドに沿ってF2を選び、既存の親フォルダと新しいフォルダ名を指定して生成します。アプリのインストール先や、すでに使っているプロジェクトへ重ねて保存しないでください。

生成先の `START_HERE.md` が、今回の保存先・ポート・起動・変更・復元の案内です。商品一式の入口 `00_START_HERE.html` や、本体を導入する `app/START_HERE.txt` とは役割が違います。

F2では、VS Codeで「Dev Containers: Reopen in Container」を実行した後、構成ターミナル本文の「準備完了」と初期構成処理の正常終了を確かめてから、開発サーバーを起動します。接続表示が出ただけでは、準備が終わったとは限りません。

最初の画面が出たら、初回の到達点です。続けたい場合は、`guide/index.html` の「任意：変更と復元」へ進めます。アプリを閉じても生成したフォルダは残ります。再開するときは、同じHTMLガイドの「困ったとき・再開」と、生成したフォルダの `START_HERE.md` を使ってください。

## 4. 必要なら、メールでヒントを受け取る

希望される方には、準備の確認や小さな練習の案内を初回3通、その後は使い方・改善・更新の案内を週1回程度お届けします。配信をお休みする週もあります。

[メールの内容を確認して登録する]({{links.subscribe}})

登録は任意です。メールを登録・確認したことが、商品の購入認証になるわけではありません。受取や再取得は、このBrain購入済み記事から進めてください。メールの配信停止後も、購入済み商品の受取には影響しません。

## 困ったとき

[お問い合わせ窓口]({{links.support}})に、OSとツクハコの版、何をしようとしていたか、最後にできた操作、表示されたエラーを添えてください。対応範囲と期間は、購入前に掲載したサポート条件をご確認ください。

パスワード、APIキー、`.env` の中身は送らないでください。画像やログに名前や個人用のパスが写っている場合も、必要に応じて隠してから共有してください。
