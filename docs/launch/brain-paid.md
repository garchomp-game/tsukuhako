# ツクハコを受け取ったら

ツクハコをご購入いただき、ありがとうございます。最初は、使うPCに合う配布物を受け取り、同梱の案内を開くところから始めてください。

## 1. 使うPCで、この購入済み記事を開く

スマートフォンで購入した方は、使うPCで同じBrainアカウントにログインし、この購入済み記事を開いてください。

購入前の説明で提供範囲を確認し、PCに合う受取先を選びます。x64はIntel/AMDの64bit向けです。ARM・macOS向けの配布物はありません。

| OS | 受取先 | 製品ファイル |
|---|---|---|
| Linux x64 | [Linux用の受取先]({{links.linuxDownload}}) | `tsukuhako-linux-x64-0.4.4.tar.gz` |
| Windows x64 | [Windows用の受取先]({{links.windowsDownload}}) | `tsukuhako-windows-x64-0.4.4-setup.exe` |

OS別の受取セットは、製品ファイルと `START_HERE.txt`、`manifest.json`、`SHA256SUMS` の4ファイルです。同じセットを同じフォルダへ保存し、まず `START_HERE.txt` を開いてください。ZIPで届いた場合は、外箱のZIPを一度展開します。

`SHA256SUMS` はファイルの一致を照合するためのものです。ハッシュの一致だけで発行者の本人確認ができるわけではないので、この購入済み記事から案内する受取先を使ってください。

Linuxはtar.gzを展開し、中の `tsukuhako` を普段のユーザーで起動します。Windowsは未署名のexeです。警告で止まる場合はOSの保護を無効化せず、内容を控えて[窓口]({{links.support}})へ確認してください。Windows 11と実WSLでの開発経路は未確認であり、CIの成功を実機確認の代わりにはしていません。

## 2. まず、開発準備の教材を読む

アプリ上部の「学ぶ」から準備の教材を開きます。教材を読むことと、生成した環境を動かすことでは、必要な準備が異なります。

開発を始めるときは、DockerとVS Code、MicrosoftのDev Containers拡張などを用意します。WindowsではWSL 2の通常ユーザーと、同じWSLへのDocker Desktop連携、VS CodeのWSL拡張も使います。初回は必要なファイルの取得があるため、インターネットに接続して進めてください。

導入済みのものを、最初からやり直す必要はありません。「作る」の準備チェックとOS別の教材を見ながら、現在の状態を確認します。[準備の確認ガイド]({{links.setupGuide}})も利用できます。

## 3. 一つの構成を生成して、案内を開く

使いたい構成を一つ選び、既存の親フォルダと新しいフォルダ名を指定して生成します。アプリのインストール先や、すでに使っているプロジェクトへ重ねて保存しないでください。

生成先の `START_HERE.md` が、今回の保存先・ポート・起動・変更・復元の案内です。受取時の `START_HERE.txt` とは役割が違います。

F2などの画面を作る構成では、VS Codeで「Dev Containers: Reopen in Container」を実行した後、構成ターミナル本文の「準備完了」と初期構成処理の正常終了を確かめてから、開発サーバーを起動します。接続表示が出ただけでは、準備が終わったとは限りません。I1はDB用の別手順なので、その構成の `START_HERE.md` に沿って進めます。

今日は起動まで、次は変更と復元、という進め方でも大丈夫です。アプリを閉じても生成したフォルダは残ります。再開するときは、そのフォルダの `START_HERE.md` を開いてください。

## 4. 必要なら、メールでヒントを受け取る

希望される方には、準備の確認や小さな練習の案内を初回3通、その後は使い方・改善・更新の案内を週1回程度お届けします。配信をお休みする週もあります。

[メールの内容を確認して登録する]({{links.subscribe}})

登録は任意です。メールを登録・確認したことが、商品の購入認証になるわけではありません。受取や再取得は、このBrain購入済み記事から進めてください。メールの配信停止後も、購入済み商品の受取には影響しません。

## 困ったとき

[お問い合わせ窓口]({{links.support}})に、OSとツクハコの版、何をしようとしていたか、最後にできた操作、表示されたエラーを添えてください。対応範囲と期間は、購入前に掲載したサポート条件をご確認ください。

パスワード、APIキー、`.env` の中身は送らないでください。画像やログに名前や個人用のパスが写っている場合も、必要に応じて隠してから共有してください。
