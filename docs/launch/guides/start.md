# ツクハコを使い始める前に

このガイドでは、受け取ったアプリと、これから作るプロジェクトの案内を分けて確認します。

## スマートフォンで読んでいる方へ

このガイドを読んだり、メールを確認したりすることはできます。開発を始めるときは、使うPCでこのガイドを開いてください。メール確認をスマートフォンで済ませても、PCでの作業を最初からやり直す必要はありません。

## 購入済みの方は、Brainの受取案内へ

[Brainの商品記事]({{links.brainProduct}})を、購入に使ったアカウントで開きます。購入済み本文から、提供範囲を確認してOS別の受取先へ進んでください。このガイドやメール登録から、商品の購入権限が発行されることはありません。

まだ購入していない方は、Brainの無料本文にある提供物・前提条件・確認範囲・販売条件を確認できます。

Linux Mint x64向けの0.4.5は、単体debに本体・教材・初回ガイドを同梱します。ファイルマネージャーでdebを開き、OS標準の「パッケージインストーラー」で内容を確認して導入し、メニューの「ツクハコ」を起動してください。管理者認証と依存パッケージ取得の通信が必要になる場合があります。起動後は「はじめて使う」または上部の「ガイド」へ進みます。Windowsの既存0.4.4は、同梱ZIPの `00_START_HERE.html` → `app/START_HERE.txt` → `guide/index.html` を使います。

Linux版0.4.5の最初の検証対象はMint 22.3 x64で、GUI導入・メニュー起動などは実機確認が必要です。旧0.4.4のMint既存開発環境とF2の記録は、新debの試験結果ではありません。Windows版0.4.4は未署名で、Windows Server 2022のCIによる補助確認まで進んでいます。Windows 11の通常ユーザーと実WSLでの開発経路は未確認です。macOS・ARMは配布対象外です。

## アプリを開いたら、準備の教材を読む

上部の「学ぶ」から開発準備の教材を読めます。狭い画面では「目次を開く」から章を選び、本文へ戻ります。教材の閲覧と生成にアカウント登録・PC側のNode.js・ネット接続は不要ですが、初回の開発環境構築にはネット接続とDocker・VS Codeなどの準備が必要です。

Linux版0.4.5では、まずメニューから本体を起動し「はじめて使う」を開くところまでで大丈夫です。準備から初回表示までは、内蔵ガイドの「F2の初回手順」に沿って進めます。ガイドを読んだだけで開発準備完了にはなりません。[準備の確認ガイド]({{links.setupGuide}})も利用できます。

生成後にできる `START_HERE.md` は、そのプロジェクト専用の案内です。保存先・ポート・最初の変更と復元が載っています。アプリを閉じた後も、このファイルから開発を再開できます。

メール登録は任意です。未登録でも、配信停止後でも、購入済み商品の受取はBrainの購入済み本文から進められます。
