# F2で見出しを変えて、元へ戻す

F2（Next.js + TypeScript + Tailwind）の最初の練習です。生成したプロジェクトが起動し、ブラウザにトップページが表示されてから始めてください。まだ準備中なら、先に[準備の確認ガイド]({{links.setupGuide}})へ戻ります。

この操作は、0.4.4のLinux Mint 22.3 x64の既存開発環境で確認した例です。Windows 11実機の開発経路は未確認です。別の構成では変更するファイルも手順も異なるので、その構成の教材を使ってください。

## 1. 変更前を残す

VS Codeで、いま起動しているF2プロジェクトの `app/page.tsx` を開きます。次の部分を探してください。

```tsx
小さく変えて、<br />動きを確かめよう。
```

これは `h1` の内側です。元の文字列をメモへコピーし、ブラウザでも「小さく変えて、動きを確かめよう。」という大きな見出しを確認します。まだ自分で変更していない、生成直後のF2を使うのが分かりやすい練習です。

## 2. 一箇所だけ変えて保存する

`h1` タグと `className` は残し、上の内側だけを次へ置き換えます。

```tsx
わたしの練習室
```

保存したら、開発サーバーを動かしたまま、生成先の `START_HERE.md` にあるトップページのURLを開きます。大きな見出しが「わたしの練習室」に変われば、この変更を確認できています。

反映されない場合は、保存したファイル、開いているURL、開発サーバーのターミナルを確認します。URLは `localhost` の案内を使い、ポートを別の教材の例へ置き換えないでください。

## 3. 元の内容へ戻す

同じ `h1` の内側を、最初に残した内容へ戻して保存します。

```tsx
小さく変えて、<br />動きを確かめよう。
```

ブラウザでも元の見出しへ戻ったことを確認してください。ファイル全体の置き換えや、プロジェクト・Dockerデータの削除は、この練習には必要ありません。

変更前・変更後・復元後の三つを確かめられたら、この練習は完了です。続きを試す場合は、生成先の `docs/EXERCISES.md` を開きます。

表示が戻らないときは、生成先の `docs/RECOVERY.md` を確認してください。今日はここで終える場合、開発サーバーは実行中のターミナルでCtrl+Cで止められます。コンテナの停止や次回の再開も、同じ復旧教材に沿って行えます。
