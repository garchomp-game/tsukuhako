# ツクハコ｜準備を整えて、作りたいものへ

**Dev Container環境を生成するツール本体と、使い始めるためのガイド・教材**

「教材でコードは書いた。次は、自分のパソコンで何か作りたい」

そこで手が止まることがあります。何を入れるのか。どの画面でコマンドを実行するのか。エラーが出たら、どこへ戻ればいいのか。

ツクハコは、学習用のプロジェクトを生成し、同梱の教材を見ながら起動・最初の変更・復元まで進むためのデスクトップアプリです。

作っているのは、おとかです。環境を整えることが好きで、趣味としても続けています。毎回同じ準備をするなら、自動化できないか。手順を説明するだけでなく、必要な操作そのものを減らせないか。そうした工夫を、これから自分の作品を作る人にも届けたいと思っています。

## こんなときに使ってください

- ブラウザ上の学習から、自分のPCでの開発へ進みたい。
- Next.jsなどを試したいが、準備の順番で迷っている。
- 動く環境を土台にして、一箇所ずつ変えてみたい。

PCの準備も含めてすべて任せたい方や、すでにある任意のプロジェクトを自動で整えたい方には、この商品の範囲は合いません。DockerやVS Codeの準備と、教材に沿って操作する時間が必要です。

## 何が入っているか

Linux Mint x64向けの0.4.5は、単体のdebに本体・教材・初回ガイドを同梱する形です。インストール後はメニューから本体を起動し、「はじめて使う」や上部の「ガイド」から案内を読めます。Windowsは既存の0.4.4本体＋ガイドの同梱ZIPを維持しています。

目的に合う構成を選ぶと、新しいフォルダへ学習用のプロジェクトを生成します。生成先には、そのプロジェクトの保存先・ポート・起動手順・最初の変更と復元をまとめた `START_HERE.md` も作られます。

教材はアプリの中で読めます。既存教材50章で、開発準備、構成ごとの最初の一歩、練習、復旧などを扱います。Linux版0.4.5には、さらに5章の初回ガイドを同梱します。収録数は、全章を使った学習効果や全構成の実機試験を保証するものではありません。

生成できるのは、次の6構成です。

| ID | やってみたいこと | 構成 |
|---|---|---|
| F1 | フロントエンドを作る | React + Vite + TypeScript |
| F2 | Next.jsで画面を作る | Next.js + TypeScript + Tailwind |
| B1 | APIを作る | Next.js Route Handlers API |
| S1 | 画面とAPIをまとめて作る | Next.js + Route Handlers |
| S2 | ローカルのDBと組み合わせる | Next.js + ローカルSupabase |
| I1 | SQLを試す | PostgreSQLの作業環境 |

クラウドSupabaseのS3は参考資料です。プロジェクト生成の対象には含めていません。最初から全部を試す必要はなく、一つの構成で起動・変更・復元を試すところから進められます。

## 購入前に確認してほしいこと

教材の閲覧とファイル生成には、アカウント登録・PC側のNode.js・インターネット接続は不要です。生成した開発環境を初めて動かすときは、Docker、VS Codeと拡張機能などの準備、必要なファイルを取得するためのインターネット接続が必要です。

Linux Mint 22.3 x64を、新しい0.4.5 debの最初の検証対象としています。新版のGUI導入・通常ユーザーによるメニュー起動などは実機確認が必要です。次の表は**既存0.4.4の確認記録**で、新版debの試験結果ではありません。

| 環境 | 確認した範囲 | まだ確認していない範囲 |
|---|---|---|
| Linux Mint 22.3 x64 | 既存の開発環境で最終配布物の起動・教材操作・F2の生成、初期準備、表示、変更、復元、再開 | 他のLinux、何も導入していないPC、全6構成の0.4.4実機完走 |
| Windows x64 | 未署名の配布候補をWindows Server 2022のCIで導入し、教材表示・終了・削除などを補助確認 | Windows 11の通常ユーザー、初回警告、実際のWSL・Docker・VS Codeを使うF2/S2の一連の操作 |

WindowsのCIは、自動試験用の環境です。Windows 11での使い始めや開発操作の確認とは異なります。Windows版の初回提供範囲は、この実機確認または対象範囲の判断を経て確定します。

macOS・ARM向けの配布、自動更新は今回の提供対象に含めていません。生成済みのプロジェクトも自動更新されません。

## 受け取りと、その後

購入後の本文から、提供対象に合う配布物を受け取ります。Linux Mint向けは単体debをファイルマネージャーで開き、OS標準の「パッケージインストーラー」で内容を確認して導入します。管理者認証と、OS側の依存パッケージを取得する通信が必要になる場合があります。導入後はアプリケーションメニューの「ツクハコ」→「はじめて使う」から、F2の初回手順へ進みます。

Windowsの既存0.4.4は、同梱ZIP全体を展開し、`00_START_HERE.html` → `app/START_HERE.txt` → `guide/index.html` の順で進めます。Windowsの新版を提供したり、実WSLで確認済みとしたりする説明ではありません。

初回の到達点は、F2の初期処理が正常に終わり、Next.jsの最初の画面を表示するところです。生成後は、そのプロジェクトの保存先・ポート等を、生成先の `START_HERE.md` で確認します。変更・復元は、最初の画面が出た後の任意の練習として案内しています。

使い始めのヒントや更新の案内を受け取りたい方には、任意のメール登録を用意します。登録は商品の受取条件ではありません。配信を停止しても、購入済み商品の受取には影響しません。

準備を整えて、一つ変え、元へ戻してみる。その小さな往復から、自分のものづくりへ進むためのツクハコです。
