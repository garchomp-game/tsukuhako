# ツクハコの投稿ネタ帳

2026-10-23。開発中の紹介に使う未公開の素材です。全件 `draft` または `idea` で、投稿・予約はしていません。投稿日時・URLは未記録、返信・感想は未収集です。

## 運用と根拠の区分

- 状態は `idea` → `draft` → `ready` → `published`。`ready` は本人が本文と根拠を確認した状態、`published` は実際の投稿日時・URLを記録できた状態とします。原稿ができただけでは進めません。
- **本人の経験・動機**、**想定**、**実機で確認したこと**、**他者から聞いたこと・見聞きした印象**を分けます。実装を読んだ確認は `STATIC`、CIは `CI` と記録し、実機の確認へ置き換えません。
- 曖昧な記憶を「多くの初心者を支援した実績」や「顧客の声」に変換しません。今ある草稿の会話表現は、確認済みの第三者の引用ではありません。
- 返信は開発の材料です。具体的な場面・停止箇所を残し、いいねの数だけで需要や購入意思を確認済みにしません。実際の声が得られるまでは、仮説と反応を分けます。
- 明鏡は学びの参考です。ツクハコを公式提携の製品、教材の転載・再販売として説明しません。
- 投稿時点の実装・確認範囲と照合します。現時点の基準は0.4.4の[商品事実表](../../validation/release-0.4.4-followup/PRODUCT-FACTS.md)です。Linux Mintの実績をWindowsや未準備PCへ一般化しません。
- 公開・予約は本人の別の判断で行います。このネタ帳は投稿を実行する指示やスケジュールではありません。
