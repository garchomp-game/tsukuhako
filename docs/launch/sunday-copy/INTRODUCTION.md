ツクハコは、Next.jsなどのDev Container環境を生成するツールです。アプリ内の教材と、使い始めるためのガイドも一緒に届ける形で、開発・検証を進めています。

「Dev Containerが便利」と聞いて、試してみたい。でも、Docker？ WindowsならWSL？ と、準備するものの名前が次々に出てきます。その準備の現在地を確かめながら、最初のアプリを動かすところまで進むためのツールと案内を作っています。

Windows x64用・Linux x64用に分け、それぞれ一つのZIPにツール本体とガイドをまとめる形で準備しています。最初はF2という構成を一つ生成し、初期準備が正常に終わったことを確かめて、Next.jsの最初の画面をブラウザに出すところを目指します。

開発環境を初めて動かすには、Docker、VS Code、ネット接続などの準備が必要です。Linux Mint 22.3 x64の既存の開発環境でF2の一連の操作を確認しています。Windows版は未署名で、Windows 11の通常ユーザーによる実際のWSL/F2の操作や、未準備のPCでの完走は、まだ確認できていません。

同じように試したことがある方、どのあたりで迷いましたか？ 最後にできた操作や、そのとき出ていた表示を教えていただけると、案内を見直す手がかりになります。
