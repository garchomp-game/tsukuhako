ツクハコは、Next.jsなどのDev Container環境を生成するツールです。本体に教材とガイドを同梱し、開発用のフォルダーを作るところから、サンプル画面を表示するところまで案内します。

「Dev Containerが便利」と聞いて、試してみたい。でも、DockerやVS Codeなど、準備するものが分からない。そんなときに、今足りないものと、次にする操作が分かる入口を作っています。

Linux Mint 22.3 x64向けには、単体debの0.4.7を準備しています。メニューから起動して「全体の流れを読む」を開き、「はじめてのWeb画面」で最初のサンプルを表示する流れです。作成後の手順には、そのプロジェクトの保存先とURLを引き継ぎます。文字の変更・復元は、画面を表示した後の任意の練習に分けています。

開発環境を初めて動かすには、Docker、VS Code、Dev Containers拡張とネット接続が必要です。これらのソフトを自動で導入するツールではありません。何も準備していないPCや、初めて使う方が補足なしに進めるかは、これから確かめる範囲です。Windowsの既存版は、Windows 11の通常ユーザーによる実WSLでの開発操作が未確認です。

同じように試したことがある方は、どの操作で止まりましたか？ 最後にできたことや、そのとき出ていた表示を教えていただけると、案内を見直す手がかりになります。
