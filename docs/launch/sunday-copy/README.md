## 配布時の組み合わせ

- 紹介文には受取リンクや任意メール登録を載せていません。開発の紹介だけに使える候補です。
- 試用案内と購入後案内は、どちらか一方を選びます。無償の検証協力と有料商品の条件を同じ案内へ混ぜません。
- 受取案内2本は、アプリのOS別受取セットとF2一本道ガイドを別途渡す場合の**配布同伴用**です。ダウンロードページや販売条件ページの代わりにはなりません。
- 本文の「同封のF2一本道ガイドのSTART_HERE.md」は、`docs/launch/sunday-pack/START_HERE.md` を入口にした配布ガイドを指します。OS別セットの `START_HERE.txt` や、生成後のプロジェクトにできる `START_HERE.md` と区別しています。
- ガイドの必須ファイルは `START_HERE.md` / `FIRST-RUN.md` / `TROUBLESHOOTING.md` / `NEXT-STEP.md` / `FEEDBACK.md` です。ガイド担当が作成する内容と最終的に照合します。
- 本番の受取先、販売先、登録先、窓口URLは未確定です。読者用本文に仮URL・ローカルpreview・未解決変数を入れず、リンクのない候補にしました。実際の配布先を準備するまでは、受取ができる案内として単独で公開しません。
- Windowsの実機結果や提供対象を後から決めた場合は、本文の確認範囲も根拠と一緒に更新します。未検証を正常動作へ読み替えたり、自動的にLinux専用の商品へ変更したりしません。
