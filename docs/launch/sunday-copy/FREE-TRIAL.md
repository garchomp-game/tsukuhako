# F2を最初の画面まで試す方へ

ツクハコの検証にご協力いただきありがとうございます。お渡しするセットは無償の試用です。初回の案内で迷う場所を確かめるために使っていただきます。

ツクハコは、Next.jsなどのDev Container環境を生成するツールです。お使いのOSに合う一つのZIPに、ツクハコ0.4.4の本体、アプリ内の教材、使い始めるためのガイドが入っています。

今回の到達点は、F2（Next.js + TypeScript + Tailwind）の準備が正常に終わったことを確認し、最初の画面をブラウザに表示するところです。ほかの構成を比較したり、すべての教材を読んだりしてから始める必要はありません。

## 最初に開くもの

受け取ったZIP全体を展開し、展開先の **00_START_HERE.html** をブラウザで開いてください。対象の環境と必要な準備を確認し、そこから **app/START_HERE.txt** の案内に沿って、本体の照合・導入・起動へ進みます。

アプリが起動したら、**guide/index.html** の「F2の初回手順」へ進みます。F2の生成、Dev Containerへの接続、初期処理の正常終了、最初の画面の表示を順に確かめます。

ガイドを読むための追加ツールやネット接続は不要です。外部の導入先を見るときや、開発環境を初めて動かすときはネット接続が必要で、Docker、VS Codeなどの準備も行います。

F2を生成した後は、生成したプロジェクトの **START_HERE.md** に、そのプロジェクトの保存先やポートが載ります。商品一式の入口や本体の導入案内とは役割が違うため、ガイドに沿って使い分けてください。

## 確認できている範囲

Linux Mint 22.3 x64の既存の開発環境では、F2の生成から準備、表示、変更、復元、再開までを確認しています。何も準備していないPCでの確認結果ではありません。

Windows版は未署名です。Windows 11の通常ユーザーで、WSLを使ってF2を動かす一連の操作は、まだ確認できていません。この範囲で試す場合は、動作確認が必要な段階として受け取ってください。

## 途中で止まったら

**guide/index.html** の「困ったとき・再開」で、今の状態と戻り先を確認してください。ターミナルが開いただけでは準備完了ではありません。初期処理が進行中のときは次の操作を重ねずに待ち、失敗の表示があるときは同じガイドの戻り先を確認します。

進められないときは、そこで区切って構いません。同じHTMLガイドの「記録票」を参考に、OS、最後にできた操作、迷った場所、出ている表示をメモすると、次に確認する場所を整理できます。パスワード、APIキー、個人情報は記録に含めないでください。

最初の画面を表示できたら、今回の到達点です。余力があれば、同じHTMLガイドの「任意：変更と復元」で一箇所を変え、元へ戻す練習に進めます。
