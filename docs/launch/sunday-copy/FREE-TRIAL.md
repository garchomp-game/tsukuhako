# サンプル画面の表示まで試す方へ

ツクハコの検証にご協力いただきありがとうございます。お渡しするファイルは無償の試用です。初回の案内で迷う場所を確かめるために使っていただきます。

今回の到達点は、**自分で作成したプロジェクトのサンプル画面を、ブラウザーに表示すること**です。文字の変更・復元は、表示後の任意の練習です。

## Linux Mint 22.3 x64で始める

1. 受け取った **tsukuhako-linux-amd64-0.4.7.deb** をファイルマネージャーで開き、OS標準のパッケージインストーラーで名前・版を確認して導入します。管理者認証と、依存パッケージの取得のための通信が必要になる場合があります。
2. 導入が完了したら、通常ユーザーのアプリケーションメニューから **「ツクハコ」** を起動します。
3. **「全体の流れを読む」** を開き、**「サンプル画面を表示する」** の手順に沿って進めます。最初は **「はじめてのWeb画面」** を使います。

本体には教材とガイドが入っています。通常利用中も上部の「ガイド」から読めます。ダウンロードしたdebを移動・削除しても、インストール済みの本体からガイドを開けます。

開発環境を初めて動かすには、Docker、VS Code、MicrosoftのDev Containers拡張とネット接続が必要です。ツクハコはこれらを自動導入しません。ガイドを読んだだけで開発準備完了にはなりません。

フォルダーを作成したら **「サンプル画面を表示する手順へ」** を押します。今回の保存先・URLが入った案内が開くので、別の教材から値を書き写す必要はありません。VS Codeへの接続後は、初期構成の **「準備完了」と正常終了の両方** を確認してからサンプルを起動します。

## Windowsの既存版を試す場合

既存0.4.4の同梱ZIP全体を展開し、**00_START_HERE.html** → **app/START_HERE.txt** で本体を導入します。続きは **guide/index.html** の初回手順を使います。Linux版0.4.7と同じ画面・ガイドではありません。

Windows版は未署名です。Windows 11の通常ユーザーによる実WSLでの開発操作は、まだ確認できていません。この範囲で試す場合は、動作確認が必要な段階として受け取ってください。

## 途中で止まったら

お使いの版のガイドで「困ったとき・再開」を開き、今の症状に合う対処へ進みます。初期処理の途中では次の操作を重ねずに待ち、失敗した場合は表示された原因を確認します。

進められないときは、そこで区切って構いません。ガイドの記録票を参考に、最後にできた操作、迷った見出し、短いエラーを残してください。パスワード、APIキー、個人情報は含めません。

アプリを閉じた後も、作成したフォルダーの **START_HERE.md** から再開できます。再開のためにプロジェクトを作り直す必要はありません。
