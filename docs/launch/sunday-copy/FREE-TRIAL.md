# F2を最初の画面まで試す方へ

ツクハコの検証にご協力いただきありがとうございます。お渡しするセットは無償の試用です。初回の案内で迷う場所を確かめるために使っていただきます。

ツクハコは、Next.jsなどのDev Container環境を生成するツールです。Linux Mint x64向けの0.4.5は、単体debに本体・教材・初回ガイドを同梱しています。Windowsは既存0.4.4の本体＋ガイドの同梱ZIPです。

今回の到達点は、F2（Next.js + TypeScript + Tailwind）の準備が正常に終わったことを確認し、最初の画面をブラウザに表示するところです。ほかの構成を比較したり、すべての教材を読んだりしてから始める必要はありません。

## 最初に開くもの

**Linux Mint：** 受け取った **tsukuhako-linux-amd64-0.4.5.deb** をファイルマネージャーで開き、OS標準の「パッケージインストーラー」で名前・版を確認して導入してください。管理者認証は本体のシステム配置とメニュー登録のためです。OS側の依存パッケージの取得には、通信が必要になる場合があります。導入完了後は、通常ユーザーのアプリケーションメニューから「ツクハコ」を起動します。

Linux版0.4.5が起動したら、**「はじめて使う」** または上部の **「ガイド」** から「F2の初回手順」へ進みます。F2の生成、Dev Containerへの接続、初期処理の正常終了、最初の画面の表示を順に確かめます。ダウンロードしたdebを移動・削除しても、ガイドは本体から読めます。

**Windowsの既存0.4.4：** ZIP全体を展開し、**00_START_HERE.html** → **app/START_HERE.txt** の順で本体を導入・起動します。続きは **guide/index.html** の「F2の初回手順」です。

ガイドを読むための追加ツールやネット接続は不要です。外部の導入先を見るときや、開発環境を初めて動かすときはネット接続が必要で、Docker、VS Codeなどの準備も行います。

F2を生成した後は、生成したプロジェクトの **START_HERE.md** に、そのプロジェクトの保存先やポートが載ります。商品一式の入口や本体の導入案内とは役割が違うため、ガイドに沿って使い分けてください。

## 確認できている範囲

旧Linux版0.4.4は、Mint 22.3 x64の既存の開発環境でF2の生成から準備、表示、変更、復元、再開までを確認しています。新版0.4.5のGUI導入・メニュー起動などは実機確認が必要です。旧版の記録を新版や、何も準備していないPCでの成功へ置き換えていません。

Windows版は未署名です。Windows 11の通常ユーザーで、WSLを使ってF2を動かす一連の操作は、まだ確認できていません。この範囲で試す場合は、動作確認が必要な段階として受け取ってください。

## 途中で止まったら

Linux版0.4.5は内蔵ガイド、Windowsの既存0.4.4は同梱HTMLガイドの「困ったとき・再開」で、今の状態と戻り先を確認してください。本体の導入やガイドの読了、ターミナルが開いたことだけでは開発準備完了ではありません。初期処理が進行中のときは次の操作を重ねずに待ち、失敗の表示があるときは同じガイドの戻り先を確認します。

進められないときは、そこで区切って構いません。同じガイドの「記録票」を参考に、OS、最後にできた操作、迷った場所、出ている表示をメモすると、次に確認する場所を整理できます。パスワード、APIキー、個人情報は記録に含めないでください。

最初の画面を表示できたら、今回の到達点です。余力があれば、同じガイドの「任意：変更と復元」で一箇所を変え、元へ戻す練習に進めます。
