# F2を最初の画面まで試す方へ

ツクハコの検証にご協力いただきありがとうございます。お渡しするセットは無償の試用です。初回の案内で迷う場所を確かめるために使っていただきます。

今回の到達点は、F2（Next.js + TypeScript + Tailwind）の準備が正常に終わったことを確認し、最初の画面をブラウザに表示するところです。ほかの構成を比較したり、すべての教材を読んだりしてから始める必要はありません。

## 最初に開くもの

同封のF2一本道ガイドの **START_HERE.md** を開いてください。対象の環境、必要な準備、ツクハコ0.4.4を開く手順から案内しています。開発環境の初回準備には、Docker、VS Code、ネット接続などが必要です。

続いて **FIRST-RUN.md** に沿って、F2の生成から最初の画面の表示まで進みます。

F2を生成した後は、生成したプロジェクトにもSTART_HERE.mdができます。そこには、そのプロジェクトの保存先やポートが載ります。ガイドの案内に沿って使い分けてください。

## 確認できている範囲

Linux Mint 22.3 x64の既存の開発環境では、F2の生成から準備、表示、変更、復元、再開までを確認しています。何も準備していないPCでの確認結果ではありません。

Windows版は未署名です。Windows 11の通常ユーザーで、WSLを使ってF2を動かす一連の操作は、まだ確認できていません。この範囲で試す場合は、動作確認が必要な段階として受け取ってください。

## 途中で止まったら

ガイドの **TROUBLESHOOTING.md** で今の状態と戻り先を確認してください。ターミナルが開いただけでは準備完了ではありません。初期処理が進行中のときは次の操作を重ねずに待ち、失敗の表示があるときは同じガイドの戻り先を確認します。

進められないときは、そこで区切って構いません。**FEEDBACK.md** にOS、最後にできた操作、迷った場所、出ている表示を記録すると、次に確認する場所を整理できます。パスワード、APIキー、個人情報は記録に含めないでください。

最初の画面を表示できたら、今回の到達点です。余力があれば **NEXT-STEP.md** で一箇所を変え、元へ戻す練習に進めます。
