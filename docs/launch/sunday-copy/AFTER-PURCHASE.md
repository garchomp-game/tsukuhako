# ツクハコを受け取ったら

ツクハコをご購入いただきありがとうございます。ツクハコは、Next.jsなどのDev Container環境を生成するツールです。お使いのOSに合う一つのZIPに、ツクハコ0.4.4の本体、アプリ内の教材、使い始めるためのガイドが入っています。

まず、受け取ったZIP全体を展開し、展開先の **00_START_HERE.html** をブラウザで開いてください。対象の環境と必要な準備を確認し、そこから **app/START_HERE.txt** の案内に沿って、本体の照合・導入・起動へ進みます。

アプリが起動したら、**guide/index.html** の「F2の初回手順」へ進みます。F2（Next.js + TypeScript + Tailwind）の生成、Dev Containerへの接続、初期処理の正常終了、最初の画面の表示までが最初の経路です。ほかの構成を比較したり、すべての教材を読み終えたりしてから始める必要はありません。

ガイドを読むための追加ツールやネット接続は不要です。外部の導入先を見るときや、開発環境を初めて動かすときはネット接続が必要で、Docker、VS Codeなどの準備も行います。

F2を生成した後は、生成したプロジェクトの **START_HERE.md** で保存先やポートを確認します。商品一式の入口や本体の導入案内とは役割が違います。別の例にあるポートへ置き換えず、自分のプロジェクトの案内を使ってください。

## 始める前に確認すること

Linux Mint 22.3 x64の既存の開発環境では、F2の生成から準備、表示、変更、復元、再開までを確認しています。未準備のPCや、すべての環境での動作を確認したものではありません。

Windows版は未署名です。Windows 11の通常ユーザーで、WSLを使ってF2を動かす一連の操作は、まだ確認できていません。購入前に案内された提供対象と、お使いの環境を照らし合わせてください。

## 止まったときと、その次

途中で止まったら、**guide/index.html** の「困ったとき・再開」へ戻ります。ターミナルや画面が開いただけで準備完了とせず、構成処理が正常に終わったことを確認してから次へ進んでください。

同じHTMLガイドの「記録票」を参考に、OS、最後にできた操作、迷った場所、出ている表示をメモできます。パスワード、APIキー、個人情報は含めないでください。

最初の画面を表示できたら、初回の到達点です。続けて試したいときは、同じHTMLガイドの「任意：変更と復元」で、一箇所を変えて元へ戻す練習へ進めます。
