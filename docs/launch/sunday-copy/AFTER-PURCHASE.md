# ツクハコを受け取ったら

ツクハコをご購入いただきありがとうございます。まずはF2（Next.js + TypeScript + Tailwind）を一つ選び、最初の画面をブラウザに表示するところから始めましょう。

同封のF2一本道ガイドの **START_HERE.md** を開いてください。対象の環境と必要な準備を確認し、ツクハコ0.4.4を開く手順へ進みます。開発環境の初回準備には、Docker、VS Code、ネット接続などが必要です。

初回は、ほかの構成を比較したり、すべての教材を読み終えたりする必要はありません。ガイドの **FIRST-RUN.md** に沿って、F2の生成、Dev Containerへの接続、初期処理の正常終了、最初の画面の表示まで進みます。

F2を生成した後は、そのプロジェクトにもSTART_HERE.mdができます。生成時の保存先やポートはこちらで確認します。別の例にあるポートへ置き換えず、自分のプロジェクトの案内を使ってください。

## 始める前に確認すること

Linux Mint 22.3 x64の既存の開発環境では、F2の生成から準備、表示、変更、復元、再開までを確認しています。未準備のPCや、すべての環境での動作を確認したものではありません。

Windows版は未署名です。Windows 11の通常ユーザーで、WSLを使ってF2を動かす一連の操作は、まだ確認できていません。購入前に案内された提供対象と、お使いの環境を照らし合わせてください。

## 止まったときと、その次

途中で止まったら、ガイドの **TROUBLESHOOTING.md** へ戻ります。ターミナルや画面が開いただけで準備完了とせず、構成処理が正常に終わったことを確認してから次へ進んでください。

**FEEDBACK.md** には、OS、最後にできた操作、迷った場所、出ている表示を記録できます。パスワード、APIキー、個人情報は含めないでください。

最初の画面を表示できたら、初回の到達点です。続けて試したいときは **NEXT-STEP.md** の、一箇所を変えて元へ戻す練習へ進めます。
