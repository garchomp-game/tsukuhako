# ツクハコを受け取ったら

ツクハコをご購入いただきありがとうございます。ツクハコは、Next.jsなどのDev Container環境を生成するツールです。Linux Mint x64向けの0.4.5は、単体debに本体・教材・初回ガイドを同梱しています。Windowsは既存0.4.4の本体＋ガイドの同梱ZIPです。

**Linux Mint：** 受け取った **tsukuhako-linux-amd64-0.4.5.deb** をファイルマネージャーで開き、OS標準の「パッケージインストーラー」で名前・版を確認して導入します。管理者認証はシステムへの本体配置とメニュー登録のためで、OS側の依存パッケージ取得には通信が必要になる場合があります。導入完了後は、通常ユーザーのアプリケーションメニューから「ツクハコ」を起動してください。

Linux版0.4.5では **「はじめて使う」** または上部の **「ガイド」** から「F2の初回手順」へ進みます。ガイドは本体に入っており、ダウンロードしたdebを移動・削除しても読めます。

**Windowsの既存0.4.4：** ZIP全体を展開し、**00_START_HERE.html** → **app/START_HERE.txt** で本体を導入・起動し、**guide/index.html** の「F2の初回手順」へ進みます。

F2（Next.js + TypeScript + Tailwind）の生成、Dev Containerへの接続、初期処理の正常終了、最初の画面の表示までが最初の経路です。ほかの構成を比較したり、すべての教材を読み終えたりしてから始める必要はありません。

ガイドを読むための追加ツールやネット接続は不要です。外部の導入先を見るときや、開発環境を初めて動かすときはネット接続が必要で、Docker、VS Codeなどの準備も行います。

F2を生成した後は、生成したプロジェクトの **START_HERE.md** で保存先やポートを確認します。商品一式の入口や本体の導入案内とは役割が違います。別の例にあるポートへ置き換えず、自分のプロジェクトの案内を使ってください。

## 始める前に確認すること

旧Linux版0.4.4は、Mint 22.3 x64の既存の開発環境でF2の生成から準備、表示、変更、復元、再開までを確認しています。新版0.4.5のGUI導入・メニュー起動などは実機確認が必要です。旧版の記録は、新版debや未準備のPCでの確認結果ではありません。

Windows版は未署名です。Windows 11の通常ユーザーで、WSLを使ってF2を動かす一連の操作は、まだ確認できていません。購入前に案内された提供対象と、お使いの環境を照らし合わせてください。

## 止まったときと、その次

途中で止まったら、お使いの版のガイドで「困ったとき・再開」へ戻ります。本体の導入やガイドの読了、ターミナルが開いたことだけで開発準備完了とせず、構成処理が正常に終わったことを確認してから次へ進んでください。

同じガイドの「記録票」を参考に、OS、最後にできた操作、迷った場所、出ている表示をメモできます。パスワード、APIキー、個人情報は含めないでください。

最初の画面を表示できたら、初回の到達点です。続けて試したいときは、同じガイドの「任意：変更と復元」で、一箇所を変えて元へ戻す練習へ進めます。
