# Windows 11実機で残っている最小確認

CIはWindows Server 2022の条件による補助検証です。Win11通常ユーザーの初回警告、既定導入先・スタートメニューからの起動、WSL/DB保持を代替しません。

1. Windows用4ファイルを受け取り、START_HERE.txtのハッシュ照合を行う。普段のWindowsユーザーでexeを実行し、警告と導入先を記録する。OS保護を無効化しない。
2. スタートメニューのツクハコを起動し、F2の「最初の一歩」を開く。Ctrlと+で拡大し、目次の開閉・本文末尾・前後章・ヘルプ復帰を確認する。
3. 開発準備が済んでいれば、同じ通常WSL 2を選んで準備確認→helper→F2生成→Windows Code→Dev Containerの正常終了→表示→変更→復元を試す。日本語・空白パスも記録する。S2のDB起動/通常停止/保持は別の時間を確保する。
4. 読書設定と自分で生成した試験プロジェクトを保管し、削除前のファイルSHAを記録する。DBはそのDBの手順で実データを確認する。
5. ツクハコを閉じてWindowsの設定から本体をアンインストール。アプリ本体が消えたこと、読書設定・生成先・helper・WSL・DBの保持を、それぞれ実際に確認して記録する。未実施はNOT_RUN。

CI再利用コード：`tools/windows-installer-smoke.ps1`（CI限定の隔離先/タイムアウト/後片付け）と `tools/windows-installed-smoke.mjs`（実導入先のrenderer/教材/読書保存確認）。CI版はインストーラーの `/S /currentuser /D=...` と、通常のアンインストーラー `/S /currentuser` を使います。保持専用フラグは使いません。実アプリが作った隔離読書設定を比較し、WSLやDBの代用品は作りません。
