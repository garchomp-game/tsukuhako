# 帰宅後、まず5〜10分で試す範囲

環境構築全体が5〜10分で終わる保証ではありません。ネット接続・Docker・VS Code等の準備が必要なら、今回は教材の操作までで区切ってください。

1. [REPORT](REPORT.md) の自分のOSの配布物を取得する。このPCならLinux x64。ローカルの最終配布フォルダもREPORTに記載しています。最初に **START_HERE.txt** を開き、4ファイルとハッシュを確認します。
2. Linuxはtar.gzを展開し、その中の `tsukuhako-linux-x64-0.4.4/tsukuhako` を起動します。Windowsは未署名のexeを普段のユーザーで導入します。保護機能で止まった場合は、警告内容を記録するところまでにします。
3. 「学ぶ」→「最初の一歩」を開きます。Ctrlと0で100%にし、Ctrlと+を4回で200%へ拡大します。Ctrlと0で100%へ戻せます。拡大中に「目次を開く」→章を選ぶ→本文を少し読む→「困ったとき」→「学んでいた章へ戻る」を試します。本文の最後に前後章ボタンがあることも確認します。
4. 準備済みF2があれば、VS Codeで生成先の **START_HERE.md** を開きます。Reopen in Container後、構成ターミナル本文の「準備完了」と初期構成の正常終了を確認してから `npm run dev`。そのファイル記載のURLを開き、`app/page.tsx`の見出しを「わたしの練習室」へ変更・保存→ブラウザ確認→元の文字へ戻して保存→ブラウザ確認まで試します。
5. アプリを閉じて再び開き、学習中の章へ戻れるか見ます。開発サーバーやコンテナは別なので、終了するときは教材の停止手順に従ってください。
