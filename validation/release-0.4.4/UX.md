# Readerの変更と検証設計

変更前：0.4.3 Linux配布物（SHA 45ea32ae9c341b6bfa908aa2eda7072e966f58597cce4b80ef905baa1c0c73d1）。Linux Mint実機の専用Xephyr表示で再現した。画面全体と目次・本文の3領域が縦にスクロールする。200%ではviewport 575×426 CSS pxに対しdocumentが774pxあり、初期表示で本文が画面外へ押し出される。

原因はReaderのvh高さとmin-height、狭幅時の目次max-height・本文70vhの組合せが、ヘッダー等を含めてviewportを超えること。固定値を隠す処理ではなく、学習画面全体をviewport内のflex、Readerを残り高さのgridにした。

狭幅は目次を開閉し、同じgridセルに重ねる。本文のDOM・高さ・scrollTopを保ち、隠れた側はinert/aria-hiddenにしてTab移動から外す。広い幅では目次を横に出す。移行で隠れる操作にフォーカスが残らないよう、目次ボタンと選択欄間で移す。本文末尾の前後章と章一覧、上部の戻り先は読書位置によらず操作できる。

既存の読書JSON形式は変更しない。保存対象は引き続き.reader-scroll。本文ロードと章の識別子を結び付け、遅い旧章の応答を表示しない。読書位置は同じ要素へ復元する。狭幅で同じ章を選び直した場合と教材を変更して目次へ戻った場合も、非表示の目次へフォーカスを残さず、本文の見出しへ移す。標準のCtrl+plus/minus/0をメニューなしの実アプリでも使えるようにした。

`tools/verify-reader-044.mjs` は実アプリを使い、通常幅→狭幅→200%→目次キーボード開閉→見出し→前後章→ヘルプ往復→幅変更→終了/再開を確認する。生成F2の親フォルダ/新規名を入力後、学習S2で往復して対象と入力を検査する。開発版と最終配布版は別のログに記録する。CSS定数だけのテストやIPCの置換は行わない。

変更前の200%はElectron setZoomFactor(2)、変更後はネイティブX11キー Ctrl+0→Ctrl+plus×4。ズーム値2、実ウィンドウ寸法とCSS viewportをログに記録する。200%のサブピクセル丸めは1 CSS px以内を許容する。最後に最終バイナリを引数なしで起動し、保存した教材とネイティブ拡大操作を再確認する。

結果・画像・ログへのリンクはINDEX.mdとREPORT.mdを参照。
