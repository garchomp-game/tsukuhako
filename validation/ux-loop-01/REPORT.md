# UX loop 01 — 開始ボタンから保存先へ

「はじめてのWeb画面で始める」を押しても次の操作が長い準備欄の下に残る問題を修正。おすすめの構成を選んだ状態で保存先入力へ直接切り替えます。

- 開始後は案内バナーと準備欄を隠し、入力と次の操作を画面上に表示。
- 準備欄は「準備の状態を確認」で開き、「作成に戻る」で復帰。入力内容を保持。
- 準備と保存先、それぞれから開いたヘルプの見出し・戻り先を維持。
- Windowsでは選択したWSLの準備ができるまで「保存先へ進む」を有効にしない。
- 「← 戻る」で構成の選び直しが可能。内蔵ガイドも新しい流れに合わせて更新。
