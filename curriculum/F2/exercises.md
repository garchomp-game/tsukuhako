# 画面を一つずつ変える

1. `app/page.tsx` の見出しを「わたしの練習室」に変更して保存します。ホストのブラウザでトップを見て、自動反映を確認します。元へ戻すには文字列を戻して保存します。
2. `app/practice/practice-form.tsx` のカードの `bg-[#e3ebe1]` を `bg-amber-100` に変えます。Tailwindのクラスで表示が変わることを確かめます。
3. `app/about/page.tsx` に `export default function About() { return <h1>この練習室について</h1>; }` を作ります。`/about` にアクセスするとページになります。トップに `Link` を追加し、画面試験にもページ遷移を一つ追加してください。
4. 練習欄に「アイデア」と別の「理由」を追加します。`useState` は各入力に必要です。再読込後は両方消えること、scriptを含む文字もそのまま表示されることを試験します。

`page.tsx` は既定でServer Componentです。`practice-form.tsx` だけに `'use client'` を付けるのは、ブラウザの入力イベントと状態を扱う部分だからです。フォルダ全体に付ける必要はありません。HTMLを直接挿入するAPIへ置き換えず、Reactの文字列表示を使います。

自分のアプリへ置き換える場合、トップと練習ページおよび関連testsを編集します。入力の保存が必要になったらS2やI1のDB設計を学び、F2の一時状態を永続データと誤認しないようにします。
