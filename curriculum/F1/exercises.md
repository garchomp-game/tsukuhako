# 小さく変更する演習

演習前にソースを別名保存するかGitで記録します。コンテナ内で `npm run dev` を起動し、ホストのブラウザで画面を開きます。

1. `src/App.tsx` の入力ラベル「表示することば」を「今日のことば」に変更して保存します。サーバーの再起動なしでラベルが変われば、自動反映を確認できました。Reactの状態は更新内容によって保持または再作成されるため、保存を永続化とは考えません。
2. 表示領域の下に入力の行数を表示してみます。空文字を0行とするか1行とするかを決め、`text.split("\n")` などで計算します。改行のある入力、空欄、クリアを確かめます。
3. ラベルの意味を変えたら `tests/browser/input.spec.ts` のラベル指定も更新します。サーバーを止めて `npm run check`、`npm test`、`npm run test:browser`、`npm run build` を実行します。
4. `package.json` のscripts、`vite.config.ts`、`tsconfig.json`、ESLint設定の役割を一文ずつ説明します。Viteが開発・ビルド、TypeScriptが型確認、ESLintがコード確認を担います。

`useState` はブラウザの入力を保持します。`{text}` は文字列を安全に表示し、HTMLとして解釈しません。再読み込みすると状態が初期化されます。入力保存を追加したい場合は、この仕様とテストを先に変えます。

元へ戻したいときは演習したファイルだけを戻します。コンテナや依存volumeを消しても、ホストにあるソースの編集は元に戻りません。
